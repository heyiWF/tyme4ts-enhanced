示例按当前所选日期实时计算。所有取法均可在 DayAlmanac 实例上直接调用，返回文化对象或基础类型。

最小示例

import {DayAlmanac} from 'tyme4ts-enhanced';

const a = DayAlmanac.fromYmd(2025, 4, 3);
a.getClash().toString();           // 冲猴(丙申)煞北
a.getDutyAdvice().getRecommends(); // 筑堤、补垣、修屋、埋穴
a.getLifeRelation(1983).toString();// 癸命劫财，互禄，六合
a.getFolkFestivals().getName();    // 寒食节

实时校验

下列断言在浏览器内实时计算，与公开发布的黄历、政府公告逐项比对。任一不符即标红。

口径说明

  • 基准日为 2025-04-03（乙巳年三月初六，壬寅日），对照多家公开黄历。
  • 社日对照《统天万年历》「立春后五戊为春社，立秋后五戊为秋社」及公开社日表。
  • 美国补假对照 OPM 与 FederalPay 公布的 2027 年补假安排。
  • 英国银行假日对照 GOV.UK 公布的英格兰及威尔士 2025 年列表。

数据来源与许可

本项目只收录可考、可再分发的内容。凡无公开算法的栏目（原版吉数、三级时辰吉凶、出版社运程文案），一律标注为「推演」，不与原版数值混同。
