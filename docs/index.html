Tyme Enhanced

以 TypeScript 编写的传统历法与通胜引擎。零运行时依赖、单文件产物、纯整数与字符串数据，便于逐行移植到 Kotlin、Swift、Go、Rust、Python 等语言。基础历法沿用 6tail/tyme4ts，其上补齐通胜所需的神煞、择日、民俗与节假日能力。

安装

npm i tyme4ts-enhanced

// 或直接使用单文件 ES 模块
import {DayAlmanac} from './tyme.mjs';

一日通胜

import {DayAlmanac} from 'tyme4ts-enhanced';

const a = DayAlmanac.fromYmd(2025, 4, 3);

a.getLunarDay();                 // 农历乙巳年三月初六
a.getDuty();                     // 闭
a.getClash().toString();         // 冲猴(丙申)煞北
a.getWuHouDay().getName();       // 青龙头
a.getDeityFestival().getName();  // 眼光娘娘等圣诞
a.getCombineZodiacNumbers().toString(); // 猪 07 19 31 43
a.getMonthGeneral().getName();   // 河魁
a.getLifeRelation(1983).toString(); // 癸命劫财，互禄，六合

核心概念

  • SolarDay / LunarDay / SixtyCycleDay：公历、农历、干支三种视角的同一天，可互相转换。
  • DayAlmanac：以一个公历日为基准的通胜聚合入口，一次取出全部栏目。
  • Culture 体系：所有名物（神煞、方位、建除、星宿……）皆为可比较、可 next() 循环的文化对象。
  • 数据表一律以字符串或整数数组编码，不依赖 JSON 文件与运行时资源。

API 概览

DayAlmanac

通胜聚合：宜忌、神煞、冲煞、胎神、方位、时辰、九宫、择日、神诞、号码、解梦、风水、取名。

WuHouDay

诸葛武侯出行择日，三元将军值日，含吉凶与断语。

Clash

日冲煞，输出「冲猴(丙申)煞北」。

LifeRelation

年命与日辰：十神、互禄、进禄、贵人、六合、三合。

HourFortune

十二时辰黄道黑道，兼记贵人、日禄、六合。

NineStarChart / Palace

九宫飞星，洛书轨迹顺逆飞布。

ZodiacNumbers

生肖号码，含六合、三合与年肖三组。

MonthGeneral

十二月将，中气换将。

DeityFestival

《玉匣记》神明诞辰，农历月日索引。

DreamOracle

《周公解梦》公有领域文本，逐日一则。

Naming / ElementBalance

八字五行统计、身强身弱、喜用五行与双字名建议。

ZodiacFortune

生肖流月运程，依六合、三合、冲、刑、害、破断吉凶。

HolidayCalendar / HolidayRule

多地区节假日：公历、农历、第几个星期几、复活节、节气五类规则，可导入逐年公告数据。

IcsCalendar / IcsEvent

解析 iCalendar，将年度循环事件转为 tyme 的 Event。

Era

日本年号、佛历、民国、主体纪年换算。

准确性说明

节气、朔望、农历月建依寿星天文历算法，节气时刻精度到秒（1900–2100 年与官方历书一致）。已知边界：SolarTerm.getSolarDay() 使用粗算值，1930 年前有 5 例节气日与精算结果跨日；回历为算术历，与观月历可能相差一日；宜忌、神煞各流派互有出入。
